# 多语言维护

使用 **i18next** 管理翻译和英文回退，**Astro 内置 i18n 配置与静态路由**生成各语言页面。英文为默认语言，路径是 `/`；简体中文路径是 `/zh/`。项目 Pages 部署会自动加上基础路径，例如 `/mlii/zh/blog/`。

## 添加新语言

1. 复制 `src/i18n/locales/en.json` 为新的 JSON，例如 `ja.json`，翻译其中的字符串。保留 `{{count}}` 等插值变量；复数形式遵循 i18next 的规则。
2. 在 `src/i18n/config.mjs` 导入它，并在 `languages` 中增加一项：

```js
import ja from './locales/ja.json' with { type: 'json' };

export const languages = {
  // 保留已有 en 和 zh 配置
  ja: { label: '日本語', short: '日本語', htmlLang: 'ja', messages: ja },
};
```

3. 运行 `npm run verify`。语言选择器、页面路由、搜索索引、RSS、Markdown 下载和 hreflang 会自动包含新语言，不需要逐页复制组件。

界面翻译可以分批加入，缺失的键会回退为英文。代码块控件的翻译位于 JSON 的 `code` 分组，构建时自动注册给 Expressive Code；其中折叠行数的 `{lineCount}` 使用该库的插值语法，应原样保留。

## 翻译文章和项目

英文原文定义内容 ID。译文保持相同相对路径：

| 英文原文 | 中文译文 |
| --- | --- |
| `src/content/blog/t/hello.md` | `src/content/translations/zh/blog/t/hello.md` |
| `src/content/blog/l/authoring-reference.mdx` | `src/content/translations/zh/blog/l/authoring-reference.mdx` |
| `src/content/portfolio/example-project.md` | `src/content/translations/zh/portfolio/example-project.md` |

译文包含自己的 frontmatter、标题、描述和正文。保留文章 ID、分类路径、日期和项目年份；技术标签可继续使用原名。暂缺或设为草稿的文章译文，会在对应语言页面显示英文原文和提示。当前五篇示例内容均已提供中文版本。

使用稳定的标题 ID，以便语言切换后保留当前章节：

```md
## 分步代码 {#code-walkthroughs}
```

MDX 会把大括号视为 JavaScript，所以需要转义：

```mdx
## 分步代码 \{#code-walkthroughs\}
```

ID 应与英文标题生成的 ID 相同。构建检查会核对当前中英文页面的标题 ID。MDX 导入组件时，需要按译文的实际目录深度调整相对路径。

## 组件中的使用

```ts
import { translator, localizedPath } from '../i18n';
const t = translator(locale);
t('list.posts', { count: 2 });
localizedPath('/blog/', locale);
```

Astro 和 Svelte 组件显式接收 `locale`，共享页面模板位于 `src/views/`。每种语言使用独立的 i18next 实例，避免静态构建同时渲染不同语言时互相覆盖。浏览器 custom elements 使用 `pageTranslator()` 读取当前文档语言。

资源 URL（图片、字体等）继续用 `withBase()`；页面链接使用 `localizedPath()`。不要手动拼接 `/zh` 或仓库前缀。

## 偏好和范围

选择语言后，浏览器保存 `mlii01-locale`。切换保留页面、查询参数和片段；以后直接访问根首页会使用已保存语言。明确打开某种语言的深层链接时，尊重链接本身。浏览器阻止存储时，语言切换和静态链接仍可使用。

导航、列表、搜索、主题菜单、目录、文章操作、编辑器与游戏控件均使用翻译资源。终端命令名、Unix 风格命令帮助/错误及文字冒险叙述仍为英文；Wordle 的词表选择独立于站点语言。切换语言不会覆盖已保存的虚拟文件、笔记和命令历史；已保存的文章副本也保留原内容。

参考：[i18next API](https://www.i18next.com/overview/api)、[Astro 国际化](https://docs.astro.build/en/guides/internationalization/)。
